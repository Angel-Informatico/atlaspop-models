# atlaspop-models

Modelos 3D de aviones y pinturas (liveries) para [Atlas Pop](https://map.angeldev.fr.eu.org), convertidos a glTF (.glb) y WebP.

Origen: proyecto [FlightGear](https://www.flightgear.org) / [FGAddon](https://wiki.flightgear.org/FGAddon). Licencia: **GNU GPL v2 o posterior** (ver `LICENSE`).
Los modelos se han simplificado (menos polígonos) y sus texturas comprimidas. Autores y enlaces al código fuente original: `CREDITS.json`.

Estructura: `index.json` (catálogo), `<modelo>/model.glb`, `<modelo>/tex/*.webp`, `<modelo>/liv/<ICAO>-N.webp` (pinturas por aerolínea).
